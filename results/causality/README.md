# `results/causality/` — the affinity–processivity investigation

**Status: closed in the negative.** The question this directory was created to answer — *does
primer retention quantitatively account for the TPP1-dependent processivity increase, without a
mechanical signal?* — cannot be answered from processivity data. That is a result about the model
equations, not a claim about all possible experiments, and this directory records exactly where the
boundary sits.

The write-up is [`paper/MANUSCRIPT.md`](../../paper/MANUSCRIPT.md). This file is the index.

## What was established, at four levels of confidence

| finding | classification | where |
|---|---|---|
| Extension-rate enhancement (B) and affinity-mediated retention (C1) are the same function of the observable; under matched *s* the distributions are identical | **exact, within the model class** | §3, Fig 1 |
| Scale invariance: *s*(λθ) − *s*(θ) = 0 exactly, so no absolute rate is recoverable at any precision | **exact** | §3 |
| Affinity is not one hypothesis: *R* = *k*_off²/(*k*_off + [P]*k*_on), so matched-*K*_d variants differ by a factor λ confounded with *k*_loss | **exact** | §4, Fig 2 |
| B vs C2 has at most one crossing, at *P*\* whose **sign** decides whether a crossing exists at all | **exact** | §8, Fig 3 |
| *r*(*n*) is bounded by min(*s*,*s*₂) and max(*s*,*s*₂); it converges to the longest-lived species; the minority takes over at *n*\* = 1 + ln(1/κ)/ln(ρ) | **exact** | §5–6, Fig 4 |
| The tail slope depends on the read window: true *s* = 0.60 reads 0.61 → 0.95, a 12-fold change in implied *k*_loss/*k*_ext | **exact given a mixture; practical relevance simulation-derived** | §6, Fig 5 |
| Processivity vs [P] has structural rank 3 of 4; direct binding is the only measurement that adds rank, and it does not rescue *k*_loss | **computed** | §7, Fig 6 |
| What TPP1 actually changes | **unresolved** | — |

**Everything above is conditional on a kinetic scheme.** A mathematically exact result within a model
is not an experimentally established biological fact; that distinction is the reason this directory
exists in its current form.

## What is not here, and why

- **No fitted model.** The deposited source data contain one scalar per replicate and **no
  product-length distribution**, so the distribution models cannot be fitted at all.
- **No ΔRAP.** It is not computable from the deposited values, and the preregistration says so.
- **No dNTP × TPP1 experiment.** Rejected as non-discriminating: an interaction of 1.62 can arise
  from nucleotide-dependent pausing with no change in extension rate, and the interaction in the
  feasible concentration window was 1.00/0.85/0.84.
- **No mechanism claim.** See `MECHANISM_CLASSIFICATION.md` §9.

## The next thing to do

importance for that dataset and should be reported as such. If φ > 0 and the majority *s* falls below
the tail slope, the result predicts the whole published comparison is window-limited. This is
**gate 3** and it needs no new experiment.
