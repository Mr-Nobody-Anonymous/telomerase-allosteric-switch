# Figures

All six figures are generated by [`../make_figures.py`](../make_figures.py), which reads the same
equations verified by `scripts/mechanism_classification_checks.py`. Each is written as a 300 dpi PNG
and a vector PDF. `MANIFEST.json` records the PNG sizes so a silent change is visible in a diff.

```bash
python paper/make_figures.py
```

Colour is the Okabe–Ito qualitative palette (colour-blind safe). No panel relies on colour alone —
line style and direct labels carry every distinction.

| file | panel content | what it establishes |
|---|---|---|
| `fig1_collapse` | (a) *s* vs [P] for WT, B, C1, C2; (b) *P*(≥*n*) for two mechanisms at equal *s* | only C1 leaves the plateau unchanged; equal *s* means identical data |
| `fig2_affinity_variants` | (a) WT, C1a, C1b at matched *K*_d; (b) *R*/*k*_off; (c) *R* | *K*_d fixes the shape, *k*_off fixes the size; the two differ by λ, confounded with *k*_loss |
| `fig3_crossing` | *s*_B − *s*_C2 vs [P] for a positive and a negative *P*\* | the sign of *P*\* decides whether a crossing exists at all |
| `fig4_mixture_ratio` | (a) *r*(*n*) for four mixtures with the bound; (b) one distribution read over three windows | the ratio is bounded, and the readout is set by the window |
| `fig5_window_dependence` | (a) reported tail slope vs window; (b) implied *k*_loss/*k*_ext | the same data spans a 12-fold range of inferred loss |
| `fig6_identifiability` | (a) singular values; (b) relative SEs; (c) TOST replicates | rank 3 of 4; binding does not fix *k*_loss; the cost of an equivalence design |

Legends as they appear in the manuscript are in [`../MANUSCRIPT.md`](../MANUSCRIPT.md) § *Figure legends*.
